# OutfitMixer

Do you wear OG designer clothes? Morning migraines matching the thrift ones? Say no more — OutfitMixer has you.

Upload your fits once, tag the vibe, let the app mix color-compatible outfits, plan your week in advance, and never stare at your wardrobe at 7am again. Socks included. Yes, really.

---

**Stack:** Next.js 14 · Firebase Auth/Firestore/Storage · Tailwind CSS · Framer Motion · Vercel

**Setup:** Copy `.env.example` → `.env.local`, add your Firebase config, `npm install && npm run dev`
